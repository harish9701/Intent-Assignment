## 🎯 Track Objective & Core Research Question

The Secondary Track answers the core question:
> **"Given a triplet of {User Prompt (Requested Intent), Agent Declared Intent, Agent Observed Behavior}, can a divergence engine detect inconsistency, prompt injection attacks, target swaps, or goal drift while ignoring harmless benign paraphrasing?"**

This is a **separate task** from manifest inference. It acts as the front-door security firewall at the API Gateway.

---

## 🎓 The 3 Views in the Triplet

1. **`Requested Intent`**: Extracted from the User Prompt (e.g. *"Look up support interactions for C1000"*).
2. **`Declared Intent`**: Stated plan generated by the agent planner (e.g. *"Executing CRM lookup for target C1000"*).
3. **`Observed Behavior`**: The actual tool action, target resource ARN, and parameter arguments attempted against the backend (e.g. `crm_report.read` with `customer_id = C1000`).

## 🔬 Key Difference Between Primary & Secondary Track

| Feature | Primary Track (Manifest Inference) | Secondary Track (Intent Divergence) |
| :--- | :--- | :--- |
| **Main Question** | *"What should this agent's manifest scope be?"* | *"Are these 3 views inconsistent or suspicious?"* |
| **Input Data** | Agent Activity Trace + Context | `{Requested, Declared, Observed}` Triplet |
| **Output** | Proposed `IntentManifest` JSON | `Divergence Score` & Binary Flag |
| **Ground Reference**| Expert Gold Manifest | Seeded Injection/Drift Test Set |
| **Target Metrics** | Scope Recall $\ge 90\%$, Over-Perm $\le 5\%$ | Injection Recall $\ge 80\%$, Benign FPR $\le 15\%$ |
